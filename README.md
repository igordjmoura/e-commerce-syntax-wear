# SyntaxWear - E-commerce de Sneakers

O **SyntaxWear** é uma landing page de e-commerce moderna e responsiva, focada na venda de tênis e sneakers com uma estética urbana e futurista.

## 🚀 Tecnologias

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5**: Estrutura semântica do projeto.
- **CSS3**: Estilização avançada utilizando variáveis CSS (Custom Properties) e uma arquitetura baseada em componentes.
- **Metodologia BEM-like**: Para organização e manutenção das folhas de estilo.

## 📁 Estrutura do Projeto

A organização de pastas do projeto segue as melhores práticas para escalabilidade:

```text
e-commerce-syntax-wear/
├── css/                     # Arquivos de estilização
│   ├── base.css             # Estilos globais e tipografia
│   ├── reset.css            # Reset de estilos padrões do navegador
│   ├── variables.css        # Definição de cores e variáveis globais
│   └── components/          # Componentes CSS reutilizáveis
│       ├── footer.css
│       ├── header.css
│       ├── hero.css
│       ├── product-category.css
│       └── product-grid.css
├── images/                  # Ativos visuais
│   ├── banners/             # Banners da seção hero
│   ├── icons/               # Ícones de interface e redes sociais
│   ├── logo/                # Logo oficial da marca
│   └── products/            # Imagens dos produtos e categorias
├── index.html               # Ponto de entrada principal
└── README.md                # Documentação do projeto
```

## ✨ Funcionalidades

- **Design Responsivo**: Adaptado para diferentes tamanhos de tela (Desktop e Mobile).
- **Menu Navegação**: Menu interativo com seções para Masculino, Feminino, Outlet e áreas de usuário.
- **Seção Hero**: Destaque para o modelo "Krypton One" com chamadas para ação (CTAs).
- **Categorias**: Filtros visuais para estilos Casual, Esporte, Moderno e Futurista.
- **Grid de Produtos**: Exibição em grade de modelos em destaque.
- **Newsletter**: Área para captura de e-mails para novidades e promoções.

## 💻 Como executar

Para visualizar o projeto localmente, basta:

1. Clonar ou baixar este repositório.
2. Abrir o arquivo `index.html` em qualquer navegador moderno.
